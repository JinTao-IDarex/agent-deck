# Style Spec · 工卡人物肖像

供 `work-badge-portrait` 深读。**输出仅肖像**，不做工卡文字排版。

参考：`../assets/ref-portrait-4x5.jpg`（首选）· `ref-badge-*.png`（仅看左侧人物区）。

## 视觉锚点

现代科技公司工卡人物：扁平矢量感半身插画、米白纸色背景、克制配色、无场景。

## 色板

| 用途 | 值 |
|------|-----|
| 肖像底 | `#F6F1E8` 或 `#F0EBE1` |
| 可选外框衬底 | `#EDE6D8` |

**点缀色（服装/领口/袖口等，一人一处即可）**

`#E07A5F` 珊瑚橙 · `#3D5A80` 靛蓝 · `#6B9080` 鼠尾草绿 · `#D4A373` 芥末黄 · `#6C757D` 石板灰蓝 · `#C97B84` 陶土粉 · `#2A9D8F` 深青 · `#BC6C25` 暖棕 · `#6D597A` 深紫 · `#E76F51` 赤陶橙

## 构图（4:5 肖像）

```
┌─────────────┐
│   纸色留白   │
│  ┌───────┐  │
│  │  脸   │  │  ← 脸在上 1/3
│  │  肩线 │  │  ← 半身入画
│  └───────┘  │
│   纸色留白   │
└─────────────┘
   宽:高 = 4:5
```

- 正面或微侧半身，头+肩完整
- 背景纯纸色，无场景、无 UI 相框、无文字
- 线面扁平，可有轻微质感，勿照片写实

## Prompt 模板（肖像专用）

```text
Slug: illustration
Asset use: agent avatar / work-badge portrait
Primary request: 生成一张工卡风格扁平人物肖像（仅人物，无文字）
Subject: <外貌：发型、脸型、表情>，<服装>，半身正面，肩线入画
Style anchor: 现代科技公司工卡人物插画 — 扁平矢量感，米白纸色背景 #F6F1E8，克制色块与细线，非写实照片
Composition/framing: 竖向 4:5，脸在上 1/3，四周纸色留白，构图干净
Color: 纸色底 #F6F1E8；肤色/发色/服装为主；至多一处点缀色 <hex>（领口或袖口等）
Text: none — 无任何文字、字母、数字、Logo、水印
Constraints: 仅 1 人；半身完整含双肩；扁平插画；背景纯纸色无场景
Avoid: 写实照片、复杂背景、多角色、霓虹色、玻璃拟态、工卡排版、未要求的装饰
```

参数：`size=1024x1536`（或 `1024x1280`）· `quality=medium|high`

## 从旧工卡取肖像（仅编辑已有样例时）

若手头只有完整工卡 PNG：裁左区 x 8%–48%、y 8%–95%，再收成 4:5（512×640）。**新需求请直接按肖像模板生成**，不要先出整卡再裁。

## 检查清单

- [ ] 4:5 竖图，仅 1 人半身，含双肩
- [ ] 脸在上 1/3，无裁脸
- [ ] 纸色背景，无场景
- [ ] 无任何文字
- [ ] 画风与 `ref-portrait-4x5.jpg` 同一语言
