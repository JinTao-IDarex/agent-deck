# 工卡人物肖像

锁定 AI Mange 工卡人物画风：现代扁平插画 + 米白纸色背景。**只交付人物肖像**，不做姓名/职责/工具等工卡排版。

生成前先读 [references/style-spec.md](references/style-spec.md)。

参考资产（只取左侧人物画风，忽略右侧文字区）：
- `assets/ref-portrait-4x5.jpg`（首选，512×640）
- `assets/ref-badge-frontend.png` · `assets/ref-badge-growth.png`（整卡样例，仅作风格锚点）

## 交付物

**唯一输出：4:5 竖向半身肖像**

| 项 | 规格 |
|----|------|
| 比例 | 4:5（宽:高） |
| 生图尺寸 | `1024x1536` 或 `1024x1280` |
| 导出尺寸 | 建议 512×640 |
| 画面 | 仅人物 + 纸色底，无文字、无相框 UI、无职责/工具 |

## 生成流程

1. **定角色**：外貌（发型、脸型、表情）、服装、可选服饰点缀色（见 style-spec 强调色池）。
2. **写 prompt**：套用 style-spec 肖像模板；**不要**写入姓名、职位、职责、工具等文字。
3. **调用生图**：`image_gen`，`size=1024x1536`，`quality=medium`（样例）或 `high`（定稿），`background` 默认不透明。
4. **目检**：半身完整（头+肩）、脸在上 1/3、背景干净纸色、无字、画风与参考一致。
5. **落盘**：拷到用户指定路径；UI 使用时 `object-contain`，避免窄框 `object-cover` 裁脸。

## 肖像硬约束

- 扁平现代插画，非写实照片
- 背景：纸色 `#F6F1E8` / `#F0EBE1`，无场景、无道具堆叠
- 构图：正面或微侧，脸在上 1/3，肩线入画，四周留白
- 色彩：肤色+发色+服装为主，至多一处低饱和点缀色，勿霓虹

## 禁止

写实照片、复杂背景、多角色、文字/水印/Logo、霓虹与玻璃拟态、8k/HDR 堆砌词、工卡排版（姓名/职责/工具栏）。
